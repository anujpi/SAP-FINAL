# Frontline Shift

AI career mobility for frontline workers, built by Team NOVESTACK for the SAP Hackfest 2026 Grand Finale (Theme 2: Inclusive Workforce).
Ravi, a warehouse operator, talks about his work. The app turns that into verified skills, an explained job match, a learning pathway, a manager decision and a Skill Passport he controls.

Build closes **Tue 3 Nov**. Finale is **Wed 4 Nov**: 10 minutes of presentation, 5 of Q&A. Every member attends. Keep the demo on one laptop, with a backup video.

Full plan, from now to a real product: `docs/PLAN.md`. Follow it, and tick its boxes as work finishes.
Architecture page: https://claude.ai/artifact/DfqnwXcHN89kbnJkotfNiK

## Commands

```bash
npm install
```
```bash
npm run watch
```
```bash
npm test
```
```bash
npm run journey
```

- `npm run watch` serves on http://localhost:4004 with hot reload.
- `npm test` runs the agent and orchestrator tests. No server needed.
- `npm run journey` runs Ravi's whole journey against the running server. **It must pass before every merge.**
- Local logins: `ravi` / `ravi` (Worker), `meera` / `meera` (Manager, Supervisor, HRAdmin), `sunil` / `sunil` (Supervisor only). Fictional test users.

Deploy needs the `mbt` and `cf` tools plus a BTP trial account:

```bash
mbt build
```
```bash
cf deploy mta_archives/frontline-shift_1.0.0.mtar
```

Before the first deploy, set `PASSPORT_SECRET`, and `LLM_MODEL` and the AI Core binding for the LLM. HANA trial instances stop every night, so restart yours each morning and before the demo.

## Product rules (never break these)

1. AI recommends, people decide. Only a Manager can create a `ReviewDecision`, and "not yet" needs a reason.
2. Low confidence means "Needs evidence". Never show or store "Missing".
3. Only verified skills score. Self-reported skills are shown but never change the score.
4. The score is plain code. The LLM may word an explanation, never produce a number.
5. Agents never call each other or the database. Only `srv/orchestrator.js` runs them and changes a worker's stage.
6. Every hand-off writes an `AuditEvent`. No personal content goes in it.
7. Voice is optional and text always works. Read back before saving.
8. Consent comes first, and revoking it erases the worker's data.
9. The Skill Passport carries only proven skills. "Not yet" decisions and raw company logs never leave the system.
10. Never claim something is live when it isn't. Label mock and sample data in the UI, and fairness figures as fictional.

## Fallbacks

- Generative AI Hub not available: set `ANTHROPIC_API_KEY` in `.env` to use the direct backup, and say so on the slide. `/worker/aiStatus()` reports the active route, and the UI must show it. With neither set, agents return a marked `degraded` fallback.
- XSUAA still failing by noon on 31 Oct: use mocked users with a role switcher. Acceptable only because all data is fictional.
- Live voice fails on stage: use text input, then the backup video.
