# SAP Signavio process models

Two standard BPMN 2.0 files, for SAP Signavio Process Manager:

| File | What it shows |
|---|---|
| `frontline-shift-before.bpmn` | How a better warehouse role gets filled today. **This is our assumption, not measured.** We haven't confirmed it with a customer, so say so. |
| `frontline-shift-after.bpmn` | The same job with Frontline Shift: the worker's words, the EWM check, the manager's proof, the certificate, SuccessFactors, and other companies with the worker's permission, through the offer, the notice period (or release early) and joining the new company with their certificates. |
| `view.html` | Opens both models in a browser, without Signavio. It holds a copy of the two files, so run `python scripts/signavio-view.py` after changing either one. |

Both load with no warnings in a standard BPMN viewer (bpmn-js). **They have not been imported into Signavio yet.** SAP says files generated by third-party tools aren't supported, so a layout problem after import is possible.

## Import them

1. Sign in to SAP Signavio Process Manager.
2. Open the **Import/Export** menu and choose the BPMN 2.0 XML import. The exact menu wording may differ on your version.
3. Choose `frontline-shift-after.bpmn`, then do the same for `frontline-shift-before.bpmn`.
4. Open each one and check the layout.

If an import fails or the layout breaks, redraw it by hand in Signavio from the same steps. It takes about 30 minutes per model. Open the file in any BPMN viewer to copy from.

- Say "modelled in SAP Signavio" only once they really are in Signavio.
- The numbers belong in the before model only after a customer gives them. We have no measured times or costs, so don't add any.
